HfO₂ Lab — 웹앱 설치

1. Chrome 또는 Edge에서 아래 주소를 엽니다.
   https://ss3031313-max.github.io/hfo2-lab/
2. 앱의 '앱 설치' 또는 브라우저의 설치 메뉴를 선택합니다.
3. '오프라인 실행 준비됨'을 확인합니다.
4. 인터넷 연결을 끊고 앱을 다시 열어 등록·분석 화면을 확인합니다.
   첫 접속과 앱 파일 준비에는 인터넷이 필요합니다.

설치 없이 실행하려면 저장소 ZIP의 압축을 모두 풀고 om_demo.html을 엽니다.
index.html을 파일로 여는 것만으로 PWA가 설치되지는 않습니다.

기존 자료 옮기기
- 기존 앱에서 '전체 백업'을 눌러 JSON을 보관합니다.
- 새 앱에서 '백업 불러오기'를 선택하고 자료·판정 기준·검토 상태를 확인합니다.
- '저장됨' 표시를 확인합니다.

자료는 현재 PC·브라우저에 저장되며 서버나 다른 PC와 자동 동기화하지 않습니다.
두께 데이터 삭제는 '02 두께 분석'에서 선택 또는 전체 삭제를 사용합니다.
삭제 후 샘플의 공정조건·OM 연결은 유지됩니다. 삭제 직후에는 복구할 수 있습니다.
브라우저 데이터 삭제·프로필 변경에 대비해 전체 백업과 원본 사진·Excel을 보관하세요.
공개 저장소에 원본 자료나 개인 백업을 올릴 필요는 없습니다.

사용법·입력 형식·분석 범위는 README.md와 sample_data/IMPORT_GUIDE.txt를 참고하세요.
