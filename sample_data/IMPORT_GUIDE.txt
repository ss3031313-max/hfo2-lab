HfO₂ Lab v0.5.0 — 샘플 엑셀·CSV 가져오기

자료 구분
동봉 입력은 기능 확인용이며 data_source는 SYNTHETIC입니다. 실제 공정·측정 결과가 아니고 OM 이미지는 포함하거나 연결하지 않았습니다.
HfO2_input_01.xlsx는 DEMO-S01, HfO2_input_02.xlsx는 DEMO-S03을 각각 다섯 위치값으로 담습니다. HfO2_sample_inputs.xlsx는 여섯 사례 통합 파일입니다.

엑셀로 바로 시작
1. om_demo.html을 엽니다.
2. 첫 화면 ‘측정 엑셀’에서 HfO2_input_01.xlsx·HfO2_input_02.xlsx를 Ctrl로 함께 선택합니다. 두 샘플이 같은 목록에 들어옵니다. 여섯 사례가 필요하면 HfO2_sample_inputs.xlsx를 선택합니다. CSV 변환은 필요 없습니다.
3. 사용할 사진이 있으면 ‘OM 사진’에서 여러 장을 첨부합니다.
4. ‘샘플 · 사진 연결’에서 확인하고 미연결·중복 후보는 ‘OM 미연결’ 선택 칸에서 직접 연결합니다. 사진 없이도 두께 판정은 확인할 수 있습니다.
5. ‘비교 보기’를 누릅니다. 두께 계산과 연결 OM 사전 분석 뒤 비교 화면으로 이동합니다.
6. 비교 화면의 사진 카드를 누르면 OM 검토로 이동합니다. 새 자동 결과는 미확인입니다. 기준이 부적절하면 수정·재분석합니다. 잘못 검출된 영역은 오른쪽 결과에서 클릭해 사유를 남기고 개수 또는 면적·개수 집계에서 제외할 수 있습니다. 원값과 수정값을 대조한 뒤 검토를 완료합니다. 애매하면 ‘추가 검토’로 남깁니다.

여러 파일을 추가하거나 바꾸기
‘가져오기’ 선택란의 기본 ‘목록에 추가’는 기존 목록에 새 파일들의 샘플을 합칩니다. 한 파일씩 나중에 올려도 앞선 샘플을 지우지 않습니다.
추가 모드에서 기존 Sample ID와 입력이 같으면 건너뛰고 기존 OM 연결도 유지합니다. 값이 다르면 충돌로 이번 배치를 적용하지 않습니다.
동시에 선택한 파일끼리 Sample ID가 중복되면 값이 같아도 임의로 골라 합치지 않습니다. 같은 샘플을 중복 포함한 단일 파일과 통합 파일을 함께 선택하지 마세요.
‘목록 교체’는 새 파일 배치로 전체 목록을 바꾸므로 유지할 샘플도 함께 넣습니다. 기존 ID의 수정값을 반영하려면 이 모드를 사용하세요.
한 파일의 읽기·검증 오류나 충돌이 있으면 배치 전체를 적용하지 않고 기존 목록을 유지합니다. 오류를 해결한 뒤 다시 첨부하세요.

기본 평균 15±2 nm·CV 10%에서의 두께 결과
DEMO-S01: 평균 15.00 nm / CV 약 1.05% / 두께 충족
DEMO-S02: 평균 18.00 nm / CV 약 0.88% / 평균 초과
DEMO-S03: 평균 15.00 nm / CV 약 21.08% / CV 초과
DEMO-S04: 위치 1개 / 평균 15.00 nm / 공간 균일도 평가 불가
DEMO-S05: 두께 미입력 / 평균·CV 평가 불가
DEMO-S06: 평균 13.00 nm / CV 0.00% / 평균 하한 경계 포함, 두께 충족

OM 미연결은 OM 충족이 아닙니다. 사진이 없으면 S02·S03은 두께 미충족, 나머지는 OM 또는 두께 평가 대기입니다.

엑셀 형식과 편집
.xlsx만 지원합니다. 이전 .xls 형식은 Excel에서 .xlsx로 저장하세요. 원본 파일을 프로그램이 수정하거나 덮어쓰지 않습니다.
읽는 시트는 ‘공정조건’과 ‘두께’입니다. 첫 행의 필수 열 이름을 유지합니다.
공정조건:
sample_id,image_id,concentration_M,coats,rpm,spin_time_s,anneal_temp_C,anneal_time_min,data_source
두께:
sample_id,position,thickness_nm,data_source

공정조건에 선택 열 image_filename을 추가하여 사진 파일명을 지정할 수 있습니다. 필수 image_id 열은 사용하지 않을 때 빈칸으로 둡니다.
엑셀에는 ‘공정조건’·‘두께’ 두 입력 시트만 있습니다. 입력 열은 숫자·문자 값만 사용합니다. 수식이 있으면 읽기를 거부하므로 측정 결과를 ‘값으로 붙여넣기’ 하세요.
두께는 nm 단위 숫자만 입력합니다. 두께가 없는 Sample은 공정조건에만 두고 두께 시트에 빈 측정 행을 만들지 않습니다.
Sample ID·출처는 두 시트에서 일치해야 하며 한 Sample 안의 측정 위치는 중복되지 않아야 합니다. 실제 측정값은 REAL_MEASUREMENT, 기능 확인용 입력은 SYNTHETIC입니다.
평균·표준편차·CV·기준 충족 여부는 프로그램이 위치별 입력과 현재 판정 기준으로 계산합니다. 수정한 동일 ID를 반영할 때는 ‘목록 교체’를 선택하고 유지할 샘플까지 포함한 파일 배치를 첨부하세요.

OM 사진 연결
확장자를 뺀 파일명과 Sample ID의 정확한 일치, image_filename의 명시 파일명, 또는 이미 등록된 image_id로 연결합니다.
예: Sample ID HFO2-001에 HFO2-001.jpg. 접미사가 다르거나 후보가 둘 이상이면 임의로 선택하지 않고 연결 대기로 둡니다.
연결 목록의 선택 칸에서 수동으로 지정할 수 있습니다. 사진 업로드 순서로 짝을 맞추지 않습니다.
기능 확인용 입력에 사진을 연결해도 실제 같은 시편의 두께 측정 결과라는 뜻은 아닙니다. 실제 자료는 원본 기록으로 대응관계를 확인하세요.

판정 수치의 근거
두께 평균 15±2 nm·CV 10%는 초기 공정 선별 목표입니다. 목표 평균의 벗어남과 위치 간 상대 산포를 나눠 보기 위한 설정이며, 평균 15 nm에서 CV 10%는 표본 SD 1.5 nm입니다. 실제 박막 성능으로 도출·검증한 값은 아닙니다.
OM 거리 5%·큰 영역 최소 16픽셀·계수 최소 2픽셀·면적률 상한 5%·밀도 상한 10개/1만픽셀은 구현 시 둔 검증 전 기본값입니다. 화면의 밀도 상한이 100이면 현재 사용자 설정이며 기본값 10과 구분합니다.
OM은 한 기준 영역의 평균 RGB와 비교하므로 기준 위치에 따라 결과가 크게 달라질 수 있습니다. 배경과 실제 입자를 구분하는 기능은 아니며 불명확하면 추가 검토로 남깁니다.
영상 처리 방법이 알려져 있다는 사실이 이 임계값의 타당성을 증명하지 않습니다. 개수는 광학적 후보 영역 수이며 실제 입자 수로 확정하지 않습니다. 실제 촬영조건의 별도 자료로 검증해야 하며 HfO₂ 산업 규격으로 설명하지 않습니다.

CSV를 쓰는 경우
왼쪽 ‘데이터’ → ‘CSV 파일 연결’에서 공정조건에 sample_process.csv, 두께에 sample_thickness.csv를 선택하고 ‘연결 분석’을 누릅니다.
동봉 CSV는 생성 당시 값이며 XLSX 수정과 자동 동기화되지 않습니다. CSV 경로를 쓰려면 수정한 두 입력 시트를 각각 CSV UTF-8로 저장하세요.

저장과 백업
등록값·등록 OM·판정 기준·검토 결과는 같은 PC·같은 브라우저의 IndexedDB에 자동 저장합니다. 창을 닫기 전 ‘저장됨’을 확인하세요.
외부 서버 저장이나 PC 간 자동 동기화가 아닙니다. 브라우저 데이터 삭제·브라우저 또는 실행 파일 위치 변경 시 복원되지 않을 수 있습니다. ‘전체 백업’ JSON을 별도 보관하고 ‘백업 불러오기’로 복원하세요.
엑셀 원본 파일 자체는 저장하지 않고 추출된 등록값을 저장합니다. 원본 엑셀·사진은 별도로 보관하세요. 상세 입력에서 등록 전 파일 선택만 한 사진은 복원되지 않아 다시 선택해야 합니다.
공정조건·두께 CSV는 표 데이터, OM 검토 CSV는 수정 전·후 수치와 제외 사유를 포함한 검토 기록용입니다. 이미지·검토 상태 전체를 옮기려면 JSON 전체 백업을 사용합니다. 수동 제외는 원본·영역·검출 설정이 일치할 때 복원하며, 검출 설정을 바꾸면 다시 검토해야 합니다.
